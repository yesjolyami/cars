# Твоё Авто Сибирь — тема WordPress

Автономная классическая тема без Elementor. Шаблоны собраны из статической версии с сохранением исходного HTML, классов, порядка CSS и JavaScript.

## Установка

1. Установить WordPress 6.4+ на PHP 8.1+.
2. Упаковать папку `tvoe-auto-siberia` в ZIP и загрузить через «Внешний вид → Темы → Добавить новую».
3. Активировать тему.
4. При первой активации тема создаёт нужные страницы и назначает главную. Ниже — список для ручной проверки:

| Страница | Ярлык | Шаблон |
| --- | --- | --- |
| Главная | `home` | использовать как статическую главную |
| Автомобили | `catalog` | Каталог автомобилей |
| Рассрочка | `installment` | Рассрочка |
| Аренда с выкупом | `rent-to-own` | Аренда с выкупом |
| Trade-in | `trade-in` | Trade-in |
| Автоподбор | `selection` | Автоподбор |
| Заявка | `application` | Заявка на подбор |
| Карточка автомобиля | `car` | Карточка автомобиля |
| Новости | `news` | Новости |
| Материал | `article` | Материал |
| Отзывы | `reviews` | Отзывы |
| Вопросы и ответы | `faq` | Вопросы и ответы |
| Контакты | `contact` | Контакты |
| Политика | `privacy` | Политика обработки персональных данных |
| Согласие | `personal-data-consent` | Согласие на обработку персональных данных |

5. В «Настройки → Чтение» выбрать созданную главную как статическую главную страницу.
6. Пересохранить «Настройки → Постоянные ссылки».

## Управление автомобилями

- В админке есть отдельный раздел «Автомобили».
- Обложка, галерея, год, двигатель, пробег, привод, взнос и платёж редактируются без кода.
- Фильтры каталога собираются из марок, годов, типов кузова, коробок передач и городов только опубликованных машин.
- На главной показываются до трёх отмеченных машин; если отметок нет, берутся первые три из каталога.
- Встроенная инструкция: «Автомобили → Как вести каталог».
- При первой активации создаются шесть текущих демо-карточек, чтобы их можно было сразу заменить реальными данными и фото.

## Управление контентом сайта

В «Внешний вид → Контент сайта» доступны без редактирования кода:

- логотип, hero-изображение главной и все изображения из папки темы через медиабиблиотеку;
- телефон, регион работы и кнопку в шапке;
- тексты hero главной и основные заголовки внутренних страниц.

Изображения сохраняются как ID вложения WordPress и не зависят от файлов темы. Если пользовательское изображение не выбрано, используется штатный файл темы. Изменения применяются на публичных страницах после сохранения настроек.

## Управление новостями

В админке появился отдельный раздел «Новости», аналогичный разделу «Автомобили»:

- «Новости → Добавить» — заголовок, полный текст, выдержка и обложка материала;
- в блоке «Рубрики» — тип публикации: выдачи, новости компании, рабочие будни, новые поступления или полезные материалы;
- в блоке «Показ на сайте» — переключатель отображения материала на главной странице;
- кнопка «Опубликовать» делает материал видимым на странице новостей, черновик остаётся скрытым.

Опубликованные записи автоматически появляются в списке новостей, фильтрах и блоке публикаций на главной. После обновления темы один раз пересохраните «Настройки → Постоянные ссылки», чтобы WordPress зарегистрировал адреса отдельных материалов.

## Продакшен-настройки

1. Открыть «Настройки → Твоё Авто — продакшен».
2. Проверить email для заявок, указать Telegram Bot Token и числовой Chat ID группы, срок хранения, юридическое наименование хостинга, размещение базы и всех фактических обработчиков.
3. Сохранить настройки и нажать «Отправить тест в Telegram»; реальную доставку подтверждает только сообщение в группе.
4. Проверить реквизиты оператора на страницах Политики и Согласия, затем поставить флажок подтверждения.
5. Пока эти данные не заполнены, тема добавляет `noindex`, чтобы нельзя было случайно открыть неготовый сайт для поисковых систем.

Ссылка-приглашение `t.me/+...` не является Chat ID и не позволяет серверу отправлять сообщения. Бота нужно создать через `@BotFather`, добавить в группу и указать её числовой Chat ID. Bot Token рекомендуется хранить в `wp-config.php`:

```php
define( 'TVOE_AUTO_TELEGRAM_BOT_TOKEN', 'токен-бота' );
define( 'TVOE_AUTO_TELEGRAM_CHAT_ID', '-1001234567890' );
// Только для группы с темами:
define( 'TVOE_AUTO_TELEGRAM_THREAD_ID', '123' );
```

## SEO

Тема самостоятельно формирует:

- уникальные `title` и `description` для всех шаблонов;
- canonical и `hreflang`;
- Open Graph и Twitter Cards;
- JSON-LD `Organization`, `WebSite`, `WebPage`, `BreadcrumbList`, `Service` и `FAQPage`;
- расширенные robots-директивы;
- ссылку на стандартный sitemap WordPress в виртуальном `robots.txt`;
- исключение служебных и демонстрационных страниц из sitemap;
- отключение sitemap пользователей WordPress.

До публикации обязательно:

1. В «Настройки → Чтение» снять флажок «Попросить поисковые системы не индексировать сайт».
2. В «Внешний вид → Настроить → Свойства сайта» загрузить квадратную иконку сайта. Можно использовать `img/logo-figma.webp`.
3. Проверить `https://домен.ru/robots.txt` и `https://домен.ru/wp-sitemap.xml`.
4. Добавить сайт в Яндекс Вебмастер и Google Search Console, подтвердить домен и отправить `wp-sitemap.xml`.
5. До замены демонстрационных данных не снимать `noindex` со страниц `application`, `car`, `news`, `article`, `privacy` и `personal-data-consent`.

Если устанавливается Yoast SEO, Rank Math или All in One SEO, собственные meta-теги и Schema темы автоматически отключаются, чтобы не появлялись дубли.

## Обновление темы

Готовый ZIP можно обновлять через WordPress как обычную тему. Каталог, заявки и настройки хранятся в базе WordPress и при обновлении темы не удаляются.

Скрипт ниже — низкоуровневый конвертер из статических HTML-файлов. Он пересобирает PHP-шаблоны и не должен запускаться поверх продакшен-темы без повторного аудита динамического каталога, форм и юридических страниц:

```bash
node wordpress/build-theme.mjs
```

После такой пересборки нужно вернуть и повторно проверить все продакшен-изменения в PHP-шаблонах и `inc/assets.php`.
